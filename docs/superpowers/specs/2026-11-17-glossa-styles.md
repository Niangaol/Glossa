# 笺疏讲解页 · 三套美术风格（设计规格）

日期：2026-11-17　状态：随 M2 施工　约束：单文件离线、零 JS、零外链、CSS 只由程序产出（AI 看不到）

## 0. 共同底线

- 内容区 class 词汇表三套共用（`lead / grid / card / steps / note / cols / kbd / scope / toc`），
  换风格只换 CSS 与版式参数，**内容 HTML 与图数据逐字不变**（验收可测）。
- 行宽：正文 ≤ 72 字符；中文 16px / 行高 1.85；代码 13px。
- 无渐变堆砌、无玻璃拟态、无大面积阴影；层次靠细边框、留白、字号与字重。
- 动效只做 CSS 且不依赖 JS：`details` 展开、`a:hover` 下划线、`figure` 淡入 120ms；
  `@media (prefers-reduced-motion: reduce)` 全部关掉。
- 可访问性：正文对比度 ≥ 7:1，强调色只用于小面积（链接、序号、图例），焦点环 2px 可见。

## 1. magazine（默认）：技术刊物

- 配色：纸 `#f6f3ec` / 墨 `#14161a` / 朱 `#b23a2a`（序号、图例）/ 黛 `#2f4f52`（旁注竖线）/ 划 `#d9d3c6`
- 字体：标题 思源宋体/Georgia 衬线（700，字距 -0.5px）；正文 系统无衬线；数据等宽
- 版式：正文 680px 居中，右侧 200px 旁注栏（`.note` 浮到侧栏）；章节以 `01 / 02` 朱色小序号起头，
  首字下沉只用于第一节导语（`.lead::first-letter`）
- 特征：目录做成页码式两栏清单；图注居中、小号衬线斜体；`code` 行内用朱色下划线而非底色

## 2. report：工程报告

- 配色：底 `#ffffff` / 墨 `#101318` / 线 `#e2e6ec` / 主强调 `#2563eb` / 次强调 `#0891b2`
- 字体：全无衬线（Segoe UI / Noto Sans SC），标题 600；数据与路径等宽
- 版式：960px 栅格，左侧 220px 粘性目录（`position:sticky`），内容 1–2 栏按块切换；
  指标条用 4 列网格 + 细线分隔（不用卡片阴影）
- 特征：章节标题带 2px 蓝色左规线；表头浅蓝底；图区白底细框，图例右上角；
  `figure` 图注左对齐、等宽小字

## 3. cards：图鉴

- 配色：暖白 `#faf7f1` / 墨 `#1b1a17` / 朱砂 `#c2452d` / 松 `#1f4e4a` / 框 `#e0d9cc`
- 字体：标题衬线（Noto Serif SC 600）+ 正文无衬线；数字用 32px 衬线大字号
- 版式：两列卡片网格（gap 20px），卡片 2px 直角细框 + 顶部 4px 色条（按语言/角色取色），
  卡片内「路径 / 一行摘要 / 指标」三行结构；章节之间用 1px 虚线分隔
- 特征：每个关键文件一张卡；目录做成卡片索引（序号 + 文件名 + 符号数）

## 4. 选择与验收

```bash
python -m glossa explain --repo <仓库> --out <目录> --style magazine|report|cards
```

- 默认 magazine；`--style list` 列出三套及一句话说明。
- 同一 doc + 同一 AI 内容换风格：`<main>` 内容区 HTML 与 `figures` 数据逐字节相同（测试）。
- 每套风格都要在真仓（SafeTrace）上出图核对：宽屏 1440、窄屏 390 各看一遍，无横向滚动。
