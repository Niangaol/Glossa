# RepoLens 实施计划：任意代码仓库的静态解析与讲解（T1–T10）

- **Goal**：把 PaperTrace 的主线从「PyTorch 模型 + 论文对账」换成「任意普通代码仓库的静态解析与人话讲解」。交付 `python -m repolens analyze/explain/facts/serve`，能分析 D:\AgentPrograms\safetrace 这类 TS monorepo，产出单文件离线讲解页与零依赖 MCP server；旧 torch/论文管线原样保留为甜头。
- **Architecture**：事实层（scan → lang/* → resolve → manifests/entries → facts → graph，产出 repo.json）／讲解层（outline → narrate → components → render）／交付层（CLI + MCP stdio）。模型只写文字，程序管事实、图与排版。
- **Tech Stack**：Python 3.13 标准库（os/json/re/ast/html/html.parser/pathlib/tomllib? 不用 tomllib 以外的第三方）+ 已有 pydeps（pytest 9.2.0、jsonschema 4.26.0）+ Jinja2（旧渲染已在用，复用同一 Environment 口径）。**零新依赖**。
- **Spec**：docs/superpowers/specs/2026-11-16-repolens-design.md（D1–D10 裁决、repo.json 字段、import 规则表、七块页面、六工具、GC29–GC34、验收六条）。
- **BASE**：ad51b52（master）　**基线**：全量 pytest **854 passed**　**旧产物零回归**：output/demo 三份 trace.json 与 index.html 逐字节不变。
- **执行方式**：Subagent-driven（每任务一个 implementer + 一个独立 reviewer + 修循环），控制器只在派发前做只读 preflight、派发后做独立复核。

## Global Constraints（每个任务都必须遵守）

1. 单文件 ≤200 行（splitlines 口径）；超了就拆，不许压 docstring 凑数。
2. 零新依赖：只用标准库 + pydeps 里已有的 pytest/jsonschema + 旧代码已用的 Jinja2。**禁 numpy/requests/tree-sitter/mcp SDK**。
3. TDD：先写红测试 → 跑红并记录原文 → 实现 → 跑绿 → ≥2 条变异探针 → 一次提交。
4. 每任务跑**全量** pytest（854 + 新增），零失败才算完；旧 papertrace/ 下任何文件**不许改**（只许 import 复用）。
5. **GC29 绝不执行被分析仓库的代码**：不 import、不 exec、不用 subprocess 跑它的脚本、不 npm/pip install。
6. **GC30 绝不读 .env* 与密钥类文件内容**（.pem/.key/.pfx/id_rsa）；只登记文件名。
7. **GC31 排除与截断必须计数并上页面**；**GC32 每文件 parse 精确度如实标注**；**GC33 unresolved import 计数 + 逐条原因，不许猜 target**。
8. 不静默兜底：解析失败进 degraded / skipped，不抛 traceback 毁掉整仓分析，也不伪造事实。
9. 产物单文件离线、零外链、零 <script>；SVG 的 xmlns 允许；页面零绝对路径（复用 papertrace.paths）。
10. 数字可溯源：程序叙述版未溯源数必须 = 0；模型版未命中只包 <mark class="untraced"> 照常渲染 + 页顶汇总；**引用不存在的 fact id 响亮拒绝**。
11. 真项目（SafeTrace/PokemonData）只手动 smoke，产物落 output/（gitignore），**私有代码绝不入库**；测试只用合成夹具。

### 本机环境事实（踩过的坑，照此执行）

- bash 在本机坏（WSL E_ACCESSDENIED / Git bash signal pipe Win32 error 5）→ **一律 pwsh**；run_code 里 execFileSync('git') 报 spawnSync EPERM → git 操作走 pwsh。
- 测试命令（可直接复制）：
```
$env:PYTHONPATH='D:\AgentPrograms\PaperTrace;D:\AgentPrograms\PaperTrace\pydeps'
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
& 'C:\Users\niangao\AppData\Local\Programs\Python\Python313\python.exe' -m pytest -q
```
- 临时目录用 tests/_tmp.py::scratch_dir(name)，**禁 tmp_path**；子进程跑 CLI 必须显式传 env['PYTHONPATH']（否则 exit 1 且 stderr 空）。
- core.autocrlf=true → **禁 git checkout -- 还原**（会把 LF 改 CRLF）；变异还原一律内存 read_bytes/write_bytes + sha256 核。
- 行数用 splitlines、字节用 read_bytes（文本模式读会吞 CRLF，之前少算 1,118 字节）；扫「有没有某种代码」按行或 AST，**不对全文跑正则**（docstring 会冒充代码）。
- run_code 的 JS 里**不能出现字面反引号**；写 Python 探针用 JS 数组 join('\n')。
- 派发书里给的模块路径与数字**必须先实测**（本项目已七次因猜路径/猜数字翻车）。

## Review Focus（spec 隐含、但测试最容易漏的五类输入）

1. **空与退化**：零文件仓库、只有二进制资产的仓库、只有一个 README 的仓库、包没有 package.json、入口命令是复合 shell。
2. **vendored 与超大**：node_modules/third_party/pythoncore-* 里的 .py 必须被排除且计数；>1MB 文件 skipped；20,000 上限截断要明示。
3. **解析失败**：SyntaxError 的 .py、括号不配对的 .ts、解码失败的字节流 → 进 degraded/skipped，不抛、不猜。
4. **import 形态**：.js 后缀指向 .ts 文件、workspace 包名、node: 内置、type-only、动态 import、Python 相对层级、unresolved。
5. **畸形讲解 payload**：未知组件名、缺必填参、假 fact id、custom 里塞 <script>/onclick/外链/javascript:、markdown 里塞链接与裸 HTML。
