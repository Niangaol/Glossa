# 未实现能力清单

2026-11-19 从代码树移出。这里记录的 **22 个模块、23 个函数、1 个类型** 当时只有
`raise NotImplementedError` 的实现，全仓库零引用：没有任何源码 import 它们，也没有任何测试
调用它们。它们占着目录、在 `test_imports.py` 里占着清单位，但不生效。

设计意图按原文保留在这里。将来要做某一条时**照此重建**，不要因为「文件没了」就重新发明一遍。

## 三、重建时要注意的

- **`diff/reverse` 是规格书里的产品卖点**，docstring 明说「不能靠概率」：重建时用写死的检测器，不许换成模型判断。
- **`detail/cache` 的键包含闭包源码**，`detail/closure` 的 docstring 强调「少一项缓存键就是错的」：两件事要一起做。
- **`detail/stale` 禁止静默覆盖**：子结论推翻父结论必须留 `conflicts`。
- **`trace_runtime/probe` 默认 CPU**：GPU 留给生成模型，不要改成默认 CUDA。
- **`treesitter_fallback` 的所有节点必须 `degraded=True`**：降级结果不许冒充真实追踪。
